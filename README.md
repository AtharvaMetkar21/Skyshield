## What is SkyShield?

SkyShield is a dual-modality machine learning system for real-time aerial threat detection. It answers one question:

> **Is that flying object a Bird, a Drone, or something else?**

It uses **two independent sensors**:
1. **Radar (D2)** — reads micro-Doppler time-series signals → classified by a Random Forest
2. **Camera (D1 + D3)** — reads electro-optical images → classified by MobileNetV3-Small CNN

Both models vote together through a **fusion engine** for the final decision. If one sensor is uncertain (blurry image, noisy signal), the other one compensates.

**Priority:** Maximise Drone Recall — it is always safer to raise a false alarm than to miss a real drone.

## Key Results

| Track | Model | Final Test Macro-F1 | Drone Recall | Speed |
|---|---|---|---|---|
| Radar (D2) | Random Forest | **1.0000 (100%)** | **100.00%** | 0.854 ms/sample |
| Vision (D1+D3) | MobileNetV3-Small | **0.8937 (89.37%)** | **92.92%** | 7.4 ms/image |
| Stress Test (20 hard images) | MobileNetV3-Small | — | **100.00%** | — |

**Calibration:** Temperature Scaling `T = 0.6426` reduces ECE from 0.0609 → **0.0154**

**Thresholds:**
- Drone alert fires when drone probability > **35%**
- Object classified as UNIDENTIFIED when max confidence < **55%**

### Data Facts

**Radar (D2):**
- 2,800 samples × 100 time-steps × 3 channels (Velocity, Amplitude, Frequency)
- 4 original classes merged to 3: Bird (0), Drone (1), Other (2)
- Split: 70% train / 15% val / 15% test — stratified

**Images (D1 + D3):**
- 7,372 cleaned, balanced images after deduplication
- Bird: 2,459 | Drone: 2,453 | Other: 2,460
- Split: 70% train / 15% val / 15% test — stratified by class and source

## How to Run

### 1. Clone the Repository

```bash
git clone https://github.com/YOUR_USERNAME/skyshield.git
cd skyshield
```

### 2. Install Requirements

```bash
pip install -r requirements.txt
```

> **Python version required:** 3.12.4
> **Note:** `torch` and `torchvision` above install CPU-only versions. For GPU support, install separately:
> ```bash
> pip install torch==2.7.0 torchvision==0.22.0 --index-url https://download.pytorch.org/whl/cu118
> ```

### 3. Download Datasets

Download the datasets listed in the [Datasets](#datasets) section and place them in their respective `data/raw/` folders.

### 4. Run Notebooks in Order

Open Jupyter and run the notebooks **in sequence** from 01 to 05:

```bash
jupyter notebook
```

| Notebook | Purpose | Run Time |
|---|---|---|
| `01_radar_audit_and_preprocessing.ipynb` | Clean and split radar data | ~2 min |
| `02_radar_model_training.ipynb` | Train radar models (RF, SVM, XGBoost) | ~5 min |
| `03_image_audit_and_preprocessing.ipynb` | Crop, clean and split image data | ~30 min |
| `04_cnn_model_training.ipynb` | Train CNN models (MobileNet, EfficientNet, InceptionV3) | ~2–4 hours (CPU) |
| `05_model_selection_and_final_test.ipynb` | Final calibration and evaluation | ~10 min |

> **Important:** Do not run notebooks out of order. Each notebook saves artefacts that the next notebook depends on.

### 5. Quick Prediction Test (Vision Model)

After running all notebooks, test the vision model on any image:

```bash
python predict_image.py "path/to/your/image.jpg"
```

Example:
```bash
python predict_image.py "C:\Users\you\Downloads\drone_photo.jpg"
```

Expected output:

## Notebooks — What Each One Does

### Notebook 01 — Radar Audit and Preprocessing
- Loads `astra_dataset.csv` (2,800 samples)
- Checks for NaN, duplicates, corrupt signals → zero found
- Maps 4 classes → 3 classes (Bird / Drone / Other)
- Winsorizes outliers using **training data only** (no leakage)
- Creates stratified 70/15/15 split, saves to `data/processed/`
- Generates: class distribution charts, signal visualisations, correlation heatmap

### Notebook 02 — Radar Model Training
- Extracts 16 statistical features from each radar time-series
- Trains **Random Forest**, **SVM (RBF)**, and **XGBoost**
- 5-fold cross-validation for each model
- GridSearchCV hyperparameter tuning
- Saves all 3 models to `models_store/`
- Generates: confusion matrices, learning curves, feature importance charts

### Notebook 03 — Image Audit and Preprocessing
- Loads D1 (826 images) and D3 (22,516 images)
- Runs YOLO bounding box cropping with 15% context padding
- Filters boxes smaller than 32×32 pixels
- Removes 128 near-duplicate images using perceptual hashing (`phash`)
- Creates stratified split, saves `image_manifest.csv`
- Generates: class distribution charts, sample crop visualisation, augmentation demo

### Notebook 04 — CNN Model Training
- Loads images via manifest, applies augmentation (flip, rotation, colour jitter)
- Fine-tunes **MobileNetV3-Small**, **EfficientNet-B0**, **InceptionV3** from ImageNet weights
- Uses class-weighted CrossEntropyLoss (higher penalty for drone misclassification)
- Saves all 3 models to `models_store/`
- Generates: training curves, confusion matrices, GradCAM visualisation, robustness stress test

### Notebook 05 — Model Selection and Final Test
- Loads all saved models
- **Temperature Scaling** calibration on validation set (`T = 0.6426`)
- **Threshold tuning** for maximum Drone Recall
- Final one-time evaluation on held-out test sets
- D1 vs D3 dataset breakdown analysis
- Error analysis (which images/signals fooled the model)
- Generates: final confusion matrices, reliability diagram, executive summary report

## Models

### Radar Track Winner: Random Forest

| Metric | Value |
|---|---|
| Validation Macro-F1 | 1.000 |
| Final Test Macro-F1 | **1.0000** |
| Final Test Drone Recall | **100.00%** |
| Inference Speed | 0.854 ms/sample |
| Model Size | 665 KB |

**Why Random Forest over SVM and XGBoost?**
All three achieved 100% accuracy. Random Forest was selected for interpretability (feature importance), stability (ensemble voting), and confirmed absence of data leakage.

### Vision Track Winner: MobileNetV3-Small

| Metric | Value |
|---|---|
| Validation Macro-F1 | 0.8991 |
| Final Test Macro-F1 | **0.8937** |
| Final Test Drone Recall | **92.92%** |
| Stress Test Drone Recall | **100.00%** |
| Inference Speed | 7.4 ms/image |
| Model Size | **3.9 MB** |
| Parameters | 2.54M |

**Why MobileNetV3-Small over EfficientNet-B0 (which had higher raw accuracy)?**
EfficientNet had 91.05% vs MobileNet's 89.87% on validation — a 1.18% difference. But EfficientNet is 16.2 MB (4× larger) and takes 29.5 ms (4× slower). For edge deployment, MobileNet is the right engineering choice. After calibration, Drone Recall of 92.92% far exceeds the safety threshold.

## Quick Prediction Test

```bash
python predict_image.py "path/to/image.jpg"
```

The script:
1. Loads `models_store/cnn_mobilenet_v3.pt`
2. Resizes input image to 224×224
3. Runs temperature-scaled inference
4. Applies drone alert threshold (35%) and rejection cutoff (55%)
5. Prints probability breakdown and final decision

**Best test images:** aerial photos of birds flying, drones in the sky, or aircraft/helicopters from below.

## System Architecture

```
REAL-TIME FUSION PIPELINE
─────────────────────────────────────────────────
  RADAR SENSOR             CCTV CAMERA
       │                        │
       ▼                        ▼ (triggered by radar)
  Feature Extraction       Image Preprocessing
  (16 statistics)          (resize 224x224, normalize)
       │                        │
       ▼                        ▼
  Random Forest            MobileNetV3-Small
  radar_probs[]            vision_probs[]
       │                        │
       └────────┬───────────────┘
                ▼
          FUSION ENGINE
          (weighted voting rules)
                │
                ▼
         FINAL DECISION
    Bird / Drone / Other / UNIDENTIFIED
                │
                ▼
         UI DASHBOARD
    (alert, camera feed, history)
─────────────────────────────────────────────────
Total decision time: ~160 milliseconds
```

**Fusion rules (in priority order):**
1. If radar drone probability > 70% → DRONE ALERT (radar dominant)
2. If vision drone probability > 70% → DRONE ALERT (vision dominant)
3. If both drone probabilities > 35% → DRONE ALERT (agreement)
4. If both bird probabilities > 60% → BIRD, no threat
5. If max confidence of both < 55% → UNIDENTIFIED + ALERT
